# Image attribution

The figures in `docs/images` are generated by `tools/diagrams/render.mjs` from the sources in
`tools/diagrams/`. The product marks inside them are not redrawn by this repository; they are the
upstream files listed below, placed unmodified except where noted.

| Mark | Source |
| --- | --- |
| Red Hat wordmark | `libs/redhat/brand-assets/2/corp/logo--on-dark.svg` on `static.redhat.com` |
| Red Hat Device Edge | `src/technology-icons/device-edge.svg` in [RedHatInsights/frontend-assets](https://github.com/RedHatInsights/frontend-assets) |
| Red Hat Enterprise Linux | `src/technology-icons/rhel.svg` in [RedHatInsights/frontend-assets](https://github.com/RedHatInsights/frontend-assets) |
| OpenShift | `src/technology-icons/openshift.svg` in [RedHatInsights/frontend-assets](https://github.com/RedHatInsights/frontend-assets) |
| OpenShift Service Mesh | `src/technology-icons/openshift-service-mesh.svg` in [RedHatInsights/frontend-assets](https://github.com/RedHatInsights/frontend-assets) |
| AMQ | `src/technology-icons/amq.svg` in [RedHatInsights/frontend-assets](https://github.com/RedHatInsights/frontend-assets) |
| Connectivity Link | Operator `ICON` in [rh-api-management/rh-connectivity-link](https://github.com/rh-api-management/rh-connectivity-link), base64-decoded to PNG |
| Red Hat build of Keycloak | `operator/src/main/kubernetes/KeycloakController.icon.png` in [keycloak/keycloak](https://github.com/keycloak/keycloak) |
| cert-manager | `logo/logo-small.png` in [cert-manager/cert-manager](https://github.com/cert-manager/cert-manager) |
| External Secrets | `assets/eso-logo-large.png` in [external-secrets/external-secrets](https://github.com/external-secrets/external-secrets) |
| Grafana | `public/img/grafana_icon.svg` in [grafana/grafana](https://github.com/grafana/grafana) |
| Ignition | `Logo-Ignition-Check.svg`, the `icon` declared by the `ignition` chart this pattern depends on |

`device-edge.svg` is the upstream file with the duplicated `width`/`height` attributes on the root
element removed. As shipped, those duplicates make the file invalid XML and no browser will render it.

Typography is Red Hat Display, Red Hat Text and Red Hat Mono from
[RedHatOfficial/RedHatFont](https://github.com/RedHatOfficial/RedHatFont), fetched at render time into
a gitignored cache rather than vendored here.

`logo.svg` is original to this repository.

`cover.png` is a synthesised illustration, used only as the page header backdrop and as the social
card image. It carries no text and depicts no real site or equipment. The hero treats it as optional:
if the file is absent the browser skips that background layer and the base gradient shows through.
